# Project Statement

## Project Title

Student Management & Academic Record System (SMARS)

---

## 1. Problem Statement

Educational institutions need to maintain a large amount of student information such as personal details, course information, marks, grades and attendance.

Managing these records manually can be time-consuming and may result in data entry mistakes, difficulty in searching records and calculation errors.

The Student Management & Academic Record System (SMARS) is developed to provide a simple computer-based solution for managing student academic records in an organized manner.

---

## 2. Project Scope

The scope of this project includes:

- Managing student personal information.
- Adding, viewing, searching, updating and deleting student records.
- Managing course information.
- Recording student marks.
- Calculating total marks and percentage.
- Calculating grades automatically.
- Determining pass/fail status.
- Recording student attendance.
- Calculating attendance percentage.
- Checking attendance eligibility.
- Generating student academic reports.
- Saving student, course and report information using text files.
- Validating user input.

The current version is a console-based Java application.

---

## 3. Target Users

The system can be used by:

### Students

Students can view and manage their academic information such as marks, grades and attendance.

### Teachers

Teachers can maintain student records, enter marks and attendance, and generate academic reports.

### College/Department Staff

Administrative staff can use the system to manage student and course information.

---

## 4. High-Level Features

### Student Management

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student

### Course Management

- Add Course
- View Courses
- Search Course
- Update Course
- Delete Course

### Marks Management

- Add marks for five subjects
- Calculate total marks
- Calculate percentage

### Grade Management

- Automatically calculate grade
- Display pass/fail result

### Attendance Management

- Record total classes
- Record attended classes
- Calculate attendance percentage
- Display attendance eligibility

### Report Management

- Generate complete student academic report
- Display student details
- Display marks and grade
- Display attendance information
- Save academic report to a text file

### Input Validation

The system validates:

- Student ID
- Course ID
- Name
- Email
- Phone number
- Marks
- Credits
- Attendance values
- Menu choices

---

## 5. Expected Outcome

The expected outcome of the project is a simple and reliable Java application that helps manage student academic records.

The system reduces manual record management and automatically performs common calculations such as percentage, grade and attendance percentage.

It also provides a structured academic report for individual students.
